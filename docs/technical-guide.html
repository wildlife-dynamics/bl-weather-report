Technical Guide

A deeper look at how the BL Weather Report workflow is built: the rainfall extraction chain, the map layer composition, the per-ranch NDVI fan-out, and Word report generation.

Download the full Technical Guide (PDF) v2.0

Version 2.0 rewrites the guide to match the current spec.yaml: it adds the interactive rainfall map (land use, ranch boundaries, electric fence, clustered rainfall layer), the rainfall-by-station summary table, and the 4-widget dashboard, all of which were added after the original guide was written. It also corrects several stale details from the earlier version — the rainfall column names and cleaning steps, the monthly-chart data source, the per-ranch NDVI CSV export (removed — no longer produced), the Word report's dynamic “generated by” author lookup (removed — generated_by is now a fixed "Ecoscope" string), the output filename (overall_report.docx, not big_life_weather_report.docx), and the dependency list, which now reflects the migration to ecoscope-platform plus the Big Life, WWF-Virunga, STE, MNC, and custom extension packages actually declared in spec.yaml.
