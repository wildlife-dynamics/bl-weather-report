BL Weather Report

Ingests rainfall gauge observations from EarthRanger, derives NDVI vegetation condition per ranch from Google Earth Engine, and produces an automated weather report and dashboard for the Amboseli ecosystem.

What it produces

  • Overall rainfall bar chart — total millimetres per gauge station for the analysis period
  • Monthly stacked bar chart — month-by-month rainfall breakdown per station, ordered by calendar month
  • Rainfall by station summary table — sortable, filterable table of total readings per station
  • Interactive rainfall map — Amboseli land use, ranch boundaries, and electric fence layers, with a clustered proportional-symbol layer of rainfall readings per station
  • Per-ranch NDVI time-series charts — current NDVI overlaid against the historic min/max/mean range, one chart per ranch
  • A data file — aggregated station rainfall readings with point geometry (GeoParquet)
  • A Word document report — every chart, the map, and all NDVI charts embedded in the Big Life weather report template
  • An interactive dashboard — 4 widgets: rainfall map, overall rainfall chart, monthly rainfall chart, and the rainfall-by-station table

Requirements

  • Access to an EarthRanger instance with rainfall_rep events logged for the analysis period
  • Access to a Google Earth Engine service account with a private key in JSON format

The Amboseli geospatial layers and the Word report template are downloaded automatically from Dropbox at run time — no additional setup is required for these.

Get started

New to the workflow? Start with the User Guide for a walkthrough of loading the template, connecting EarthRanger and Google Earth Engine, and running it. Running into an error? Check Troubleshooting first.
